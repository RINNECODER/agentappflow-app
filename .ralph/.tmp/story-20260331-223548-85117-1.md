### US-001: Complete runtime-backed onboarding handoff
Status: in_progress
Depends on: None

Description:
As a first-time AgentAppFlow user, I want onboarding to bootstrap and register a repo into the local runtime so the app transitions directly into the runtime-backed control center.

Acceptance Criteria:
- [ ] FirstRunSetupView completes bootstrap plus registration and hands a project identifier or equivalent runtime-backed selection into the main app flow.
- [ ] Example: a successful bootstrap/register flow selects the newly registered project and opens the control center with runtime data.
- [ ] Negative case: if bootstrap or registration fails, the user remains in onboarding and sees an actionable error without a half-completed transition.
- [ ] Relevant Swift tests cover the onboarding-to-runtime handoff behavior.
